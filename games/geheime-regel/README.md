# Geheime Regel
Zendo-achtige deductie met camera: teams raden een geheime regel over hun groepsfoto via klopt/klopt-niet-uitslagen van een vision-model. Zie DESIGN.md en BEGELEIDER.md.

- Test: `npm test`; sim: `npm run sim geheime-regel`.
- Nog niet getest met echte mensen of een echt vision-model.
